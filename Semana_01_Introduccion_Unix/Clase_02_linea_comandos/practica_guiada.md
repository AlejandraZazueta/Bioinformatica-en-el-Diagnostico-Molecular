# Práctica guiada 1: Introducción a Unix

## Propósito

Aplicar comandos básicos de Unix para navegar por el sistema de archivos, crear directorios, descargar, copiar, mover y eliminar archivos.

## Comandos que utilizaremos

- `pwd`
- `ls`
- `cd`
- `mkdir`
- `cp`
- `mv`
- `rm`
- `wget`
- `curl`

> No copies el símbolo `$` cuando aparezca en un ejemplo de terminal.
