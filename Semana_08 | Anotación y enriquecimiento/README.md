# Semana 8 — Anotación funcional y análisis de enriquecimiento

Esta semana trabajaremos con **anotación funcional** y **análisis de enriquecimiento**, avanzando desde una lista de genes hacia la identificación e interpretación de funciones, procesos biológicos y vías potencialmente relevantes.

## Contenidos

- Anotación funcional
- Ontologías y Gene Ontology (GO)
- Molecular Function (MF), Cellular Component (CC) y Biological Process (BP)
- Listas de genes y conjuntos funcionales
- Análisis de enriquecimiento
- Universo o *background*
- Sobrerrepresentación
- Significancia estadística y ajuste por múltiples comparaciones
- Interpretación biológica de los resultados

> **Importante:** que un término o vía esté enriquecido significa que está **sobrerrepresentado** en la lista analizada. Esto no implica necesariamente que el proceso esté activado.
